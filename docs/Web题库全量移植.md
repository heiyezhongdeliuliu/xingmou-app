# Web 端题库全量移植手册（星眸训练台）

> 目标：把 Web 便携版（QizhiTrainingPlatform-Portable）的全部 90 道题整理成题库，并标注素材与映射关系，便于直接移植到安卓端（xingmou-app）。
> 机器可读数据见同目录 [web-question-bank.json](web-question-bank.json)。

## 一、概览

| 项目 | 数量 | 来源文件 |
|------|------|----------|
| 基线评估题（BASELINE_GAMES） | **24**（18 原始 + 6 补充，其中「动作模仿」已改为观察型） | `js/onboarding-assessment.js` |
| 模块活动题（MODULE_ACTIVITY_BANK） | **66**（22 模块 × 3 题） | `js/question-logic-v2.js` |
| 合计 | **90** | — |
| 能力域 | 6（A 注意感知觉 / B 记忆 / C 执行逻辑 / D 语言沟通 / E 社会情绪 / F 生活动作） | `js/enhanced.js` |

**素材说明**：全部题目素材都是 **Unicode Emoji + 内联 SVG**（`utils.js` 的 `ICONS`），**没有任何外部图片文件**。安卓端无需打包图片资源，直接复用 Emoji 字符串即可（`QuestionDefinition.assetKey` 只用于通用占位图标，与题目素材无关）。

## 二、题目模式 → Android 类型映射

Web 端只有 5 种题目构造器，Android 端 `QuestionType` 有 6 个枚举值。映射**不能只看 mode，要结合模块语义**：

| Web 构造器 | Web mode | 含义 | 对应 Android QuestionType | 说明 |
|-----------|----------|------|---------------------------|------|
| `qChoice(prompt,target,choices,cue)` | `choice` | 点选正确答案 | `CHOICE` / `SORTING` / `SEQUENCE` | 默认 CHOICE；分类/排序类内容映射 SORTING；顺序类映射 SEQUENCE |
| `qMemory(prompt,preview,target,choices)` | `memory` | 先看 `preview`，隐藏后凭记忆选 | `MEMORY` / `SEQUENCE` | 单个/最后一个→MEMORY；序列顺序→SEQUENCE |
| `qAudio(spokenPrompt,target,choices)` | `audio` | 语音播报题干后点选 | `AUDIO` | — |
| `qObserved('spoken',prompt,cue)` | `spoken` | 儿童开口说，成人记录完成度 | `OBSERVED` | 三个固定选项：自己完成/帮助后完成/还没完成 |
| `qObserved('guided',prompt,cue)` | `guided` | 儿童跟着做动作，成人记录 | `OBSERVED` | 同上 |

**观察型题（spoken/guided）的共同字段**（`qObserved` 写死）：
- `target` = `自己完成`
- `choices` = `["自己完成", "帮助后完成", "还没完成"]`
- 判题无对错，只记 `supportOutcome`（independent / supported / not-completed）

## 三、⚠️ 关键陷阱：Web ↔ Android 模块语义错位

安卓端 [TaskCatalog.kt](../app/src/main/java/com/xingmou/data/catalog/TaskCatalog.kt) 的模块 **ID 与 Web 完全一致（P01–D03，共 22 个）**，但**部分模块的名字/语义已经改写**。**直接按模块 ID 移植会导致题目张冠李戴**，尤其 C（执行逻辑）和 D（生活动作）两个域。

### 3.1 22 模块对照表

### 3.2 语义重映射建议（按内容移植，不按 ID）

Android 对 C、D 两个域做了「重排」，把 Web 的内容换到了别的 ID 下，并新增/丢失了部分内容：

| Web 模块（内容） | 应落到的 Android 模块 | 结论 |
|------------------|----------------------|------|
| P04 听觉注意（听指令点小狗） | ❌ 无对应 | Android P04 已被「共同注意」占用；若需保留，建议**新增模块**或改回 |
| M01 物品配对（牙刷配牙膏） | ❌ 无对应 | Android M01 已被「即时记忆」占用 |
| E01 因果关系（下雨带伞） | ❌ 无对应 | Android 全 E 域都没有「因果」内容 |
| E02 分类整理（哪个不是水果） | **E01 分类推理** | 语义吻合，改 ID |
| E03 数量认知（哪组有两个） | **E02 大小排序** | 部分吻合（数量），改 ID |
| E04 计划与顺序（睡觉前刷牙） | **E03 按顺序放图片** | 语义吻合，改 ID |
| L01 图片命名（说出名字） | ❌ 无对应 | Android L01 已被「指认物品」占用 |
| L02 句子表达（看图说话） | L02 跟读词语 | 部分吻合（降到词语级） |
| D01 生活步骤训练（洗手第一步） | **D03 生活顺序** | 语义吻合，改 ID |
| D02 精细动作/点选（轻轻点星星） | ❌ 无对应 | Android D02 已被「模仿动作」占用 |
| D03 模仿/节律动作（跟节奏拍手） | **D02 模仿动作** | 语义吻合，改 ID |

**建议二选一**：
1. **以 Web 为准**：把 Android `TaskCatalog` 的 E01–E04、D01–D03、P04、M01、L01 改回 Web 的命名与语义，题库即可按 ID 直迁（改动最小、题库最完整）。
2. **以 Android 为准**：保留 Android 的 22 模块重排，把本题库 E02→E01、E03→E02、E04→E03、D01→D03、D03→D02 迁移，并**丢弃/另建** Web 独有的 P04 听觉注意、M01 物品配对、E01 因果关系、L01 图片命名、D02 精细点选 5 组内容（共 15 题）。

> 建议走方案 1：Web 的 22 模块语义更贴近评估量表（BASELINE_GAMES 的 construct/basis 字段完全对应），且 90 题全部有归属。

## 七、评分与难度规则（移植时需要一并复刻）

| 规则 | Web 实现（`question-logic-v2.js`） |
|------|-----------------------------------|
| 难度等级 | 1–5 级 |
| 自适应升降 | 连对 2 题升 1 级，连错 2 题降 1 级，单次最多 ±1 级 |
| 选项数随难度 | 难度 1 → 2 个选项；难度 2 → 3 个；难度 ≥3 → 全部 |
| 提示等级 promptLevel | 无提示=0；重复听一遍=1；给了提示=2；帮助后完成=2 |
| 完成结果 supportOutcome | `independent`（独立）/ `supported`（支持）/ `not-completed`（未完成） |
| 是否首次正确 firstCorrect | `correct===true && promptLevel===0` |
| 基线域得分 | 每域按 完全独立=1 / 支持完成=0.5 / 提示=0.55 / 重复听=0.8 / 错=0 加权平均后 ×100 |

## 八、移植建议（对照 Android `QuestionDefinition`）

`QuestionDefinition` 字段与本题库 JSON 字段的对应关系：

| Android 字段 | 本题库来源 | 说明 |
|--------------|-----------|------|
| `id` | JSON 的 `id` | 基线 `BL-X-NN`、模块 `XX-NN` |
| `moduleId` | JSON 的 `moduleId`（模块题）/ `baseline`（基线题） | **注意按第 3 节重映射** |
| `domain` | JSON 的 `domain` | A–F |
| `type` | JSON 的 `mode` + 模块语义 | 见第 2 节映射表 |
| `prompt` | JSON 的 `prompt` | audio 题把 `spokenPrompt` 合并进 prompt |
| `options` | JSON 的 `choices` | 观察型固定三项 |
| `correctOption` | `choices.indexOf(target)` | 观察型为 `null`；记忆/序列题 target 是拼接串（如 `☀️🌙`），需按字符串匹配 |
| `stimulus` | JSON 的 `preview` / `cue` / `scene` | memory 题存 preview，观察型存 cue 作展示图 |
| `previewMs` | 默认 3000 | memory 题预览时长 |
| `sourceRef` | 建议 `WEB_BANK_V1` | 区分于 Android 现有 `local-v0.7b` |

**注意点**：
1. `correctOption` 需用 `target` 在 `choices` 里求下标；遇到 `choices` 里有重复项（如 P03-01 三个 🌙）要按**第一个等于 target 的位置**或题目规则特殊处理。
2. 观察型题（spoken/guided）没有对错，`correctOption = null`，只记录 `supportOutcome` 和 `promptLevel`。
3. Web 端难度自适应（连对连错升降级、选项数裁剪）属于**运行时逻辑**，不在本题库数据里，需在安卓 ViewModel/评分层单独实现。

## 附：与 Android 现有题库的关系

Android [QuestionCatalog.kt](../app/src/main/java/com/xingmou/data/catalog/QuestionCatalog.kt) 目前是**程序化生成的占位题库**（`buildQuestions` 每模块 5 个变体，只复用少量 Emoji），**内容远少于** Web 的 90 道精编题。本题库就是用来替换 `buildQuestions` 的权威数据源——移植后建议让 `QuestionCatalog` 直接读取本题库 JSON（放入 `assets/`），或用 Kotlin 字面量一次性生成 `moduleQuestionBank`，废弃 `emojiOptions/stimulusFor/promptFor` 三个函数。
